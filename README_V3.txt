SUPERWEB V3 — SEO + GOOGLE + PWA

1) Sube todos los archivos a tu repositorio de GitHub Pages.
2) En index.html, sitemap.xml, robots.txt y las páginas de tools, cambia:
   TU-USUARIO -> tu usuario de GitHub
   TU-REPOSITORIO -> nombre del repositorio
3) Activa GitHub Pages en Settings > Pages > Deploy from branch > main/root.
4) Comprueba que la URL funciona.
5) Abre Google Search Console y añade la propiedad de tu URL.
6) Envía /sitemap.xml desde Search Console.
7) Usa "Inspección de URL" para solicitar indexación de la portada y páginas importantes.
8) Antes de publicidad, completa privacidad y contacto con datos reales y revisa las obligaciones de cookies/consentimiento aplicables.
9) Cuando tengas contenido suficiente y tráfico real, puedes solicitar monetización publicitaria si cumples las políticas del proveedor.
10) La web incluye manifest + service worker como base de PWA.

IMPORTANTE:
- El sitemap y canonical contienen marcadores que debes sustituir.
- SEO no garantiza aparecer en primeras posiciones.
- No se ha añadido un código de AdSense real: primero hay que configurar la cuenta y cumplir sus requisitos/políticas.
